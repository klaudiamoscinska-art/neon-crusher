# KERNELFALL

Active idle physics game: autonomous drones breach a rogue AI while aimed
OVERRIDE pulses sever power branches and trigger NEURAL COLLAPSE. Destroy
the main core after twelve sectors, then continue endlessly. Existing
Neon Crusher saves and the repository URL remain compatible.
Plain HTML/CSS/JS, no dependencies.

- Play locally: `python3 -m http.server 8080`, open `http://localhost:8080/`.
- Tests: `node qa/run-all.mjs` (`qa/README.md`).
- Docs: `docs/` (design, architecture, save contract, risks, roadmap,
  CrazyGames, release); working rules for Claude Code: `CLAUDE.md`.

Basic Launch package and review: `docs/KERNELFALL_BASIC.md`,
`docs/KERNELFALL_REPORT_PL.md`. No merge or deployment without owner approval.
